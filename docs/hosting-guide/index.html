Put ScenTop online

A step-by-step guide. Do the parts in order and tick the boxes as you go. Red boxes and numbers show exactly what to click.

How the pieces fit
  • Neon keeps the data (perfumes, accounts, orders). It is already set up.
  • Render runs your server so other people can open the website, admin page and app. You set this up in this guide.
  • Google Cloud and Neon Auth need to be told your new website address, or the login buttons will be blocked.
You will need: a GitHub account, Anthony (the repo is his), and your .env file open in a text editor (it is in the ScenTop folder; never share it).
Never post your .env values in chat, screenshots or GitHub. They contain passwords. Only paste them into Render's own form.

1Put the code on GitHub

Render builds your site from GitHub, so the newest code must be there.

  1. Open a terminal in the ScenTop folder (in the launcher, click Open project folder, click the address bar, type cmd, press Enter).
  2. Run this command: 
    git push origin sam
  3. Open github.com/tonytoes/ScenTop. A yellow banner says sam had recent pushes. Click Compare & pull request, then Create pull request.
  4. Ask Anthony to click Merge pull request. Render deploys from the main branch, so the code is only live after this.
If the push asks you to sign in, use your GitHub account that Anthony added to the repo.

2Create the Render account

This needs the GitHub account that owns the repo (Anthony's), or a fork of it. Easiest: Anthony does Parts 2 to 5 while you watch or screen-share.

  1. Open render.com and click Get Started.
  2. Choose GitHub to sign up. Allow Render to read your repositories.

3Create the service from the Blueprint

The repo has a file called render.yaml that already describes the whole setup, so you do not fill it in by hand.

  1. Open dashboard.render.com/select-repo?type=blueprint.
  2. Find ScenTop in the list and click Connect. If it is missing, click Configure account and give Render access to the repo.
  3. Choose the main branch.

5Tell the server its real address

  1. Open your service in the Render dashboard (it is named scentop).
  2. Your address is shown near the top, under the name. It looks like https://scentop-xxxx.onrender.com. Click it to copy.
  3. Click Environment in the left menu.
  4. Find AUTH_APP_ORIGIN, click Edit, and paste your address. It must start with https:// and have no slash at the end.
  5. Click Save, rebuild and deploy. Wait 2 to 5 minutes.

6Allow your address in Google Cloud

Without this, "Continue with Google" shows an error on the live site. Email codes and password login do not need it.

  1. Open console.cloud.google.com/apis/credentials. Make sure the project in the top bar is the one with your login setup (it shows Project1 in your screenshot).
  2. Under OAuth 2.0 Client IDs, click Scentop_Web (red box 1 below).
  1. Scroll to Authorized JavaScript origins. Click Add URI (box 1 below) and paste YOUR-ADDRESS.
  2. Scroll to Authorized redirect URIs. Click Add URI (box 2) and paste YOUR-ADDRESS again.
  3. Do not delete the two addresses already there (the long neonauth one and http://localhost:4200).
  4. Click Save (box 3).
Paste only the address, like https://scentop-xxxx.onrender.com. No /admin, no slash at the end.

7Allow your address in Neon Auth

  1. Open console.neon.tech and click the ScenTop project.
  2. In the left menu, click Better Auth (box 2 below). This is Neon Auth.
  3. Look for a setting called Trusted domains, Domains or Allowed origins. Add YOUR-ADDRESS and save.
I have not seen the inside of this page, so the exact label may differ. If you cannot find it, take a screenshot of the page and send it to me.

8Test that it works

Replace YOUR-ADDRESS with your real address. The first visit after a quiet period takes up to a minute, because the free plan sleeps.

9Change the database password

The old password was pasted in a chat, so replace it once everything works. Tell Anthony first, because his older project uses the same Neon login.

  1. In Neon, open the ScenTop project and click Connect (box 1 in the Part 7 picture).
  2. Click Reset password (box 3 below). Neon makes a new password.
  3. Make sure Connection pooling is on, then click Show password (box 2) and copy the whole connection string (box 1).
  4. Change the database name at the end from /neondb? to /scentop?. This is the step people forget.
  5. Paste it into two places: the DATABASE_URL= line in your .env, and Render → Environment → DATABASE_URL → Save, rebuild and deploy.
